# 3.8 – Threat Hunting Section Summary

**Path:** `modules/03-hunter/08-summary`

## Purpose

This is the closing synthesis module for the 3.x Threat Hunting block.

It revisits the loop introduced in 3.0:

**Question → Hypothesis → Evidence → Refine → Finding → Handoff**

The summary uses one A12 hunt to reconnect 3.1–3.7 into a complete threat-hunting workflow rather than reteaching the individual lessons.

## Curriculum status

**Section summary — no proficiency mapping.**

`3.8` is a review/synthesis number. It does not create a new knowledge or task requirement in the proficiency matrix.

## Concepts reinforced

- hunt purpose
- hunt types as primary starting signals
- topic vs testable hypothesis
- scope, population, window, telemetry, and exclusions
- distinctive search patterns
- CTI/external leads vs local evidence
- indicators vs behavior
- ATT&CK technique vs procedure/observation
- detection gap vs visibility gap
- false-negative boundary
- bounded negative findings
- evidence-based technique attribution
- hunt documentation and reproducibility
- multi-owner handoffs
- hunt-to-DE transition

## Primary exercise

One integrated A12 hunt card is used to produce:

- hunt question
- hypothesis
- scope
- findings
- limitations
- gap classification
- downstream handoffs
