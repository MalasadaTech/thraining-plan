# 3.0 – Threat Hunting

**Path:** `modules/03-hunter/00-intro`

## Purpose

This is the orientation module for the 3.x Threat Hunting block.

It introduces the hunt loop:

**Question → Hypothesis → Evidence → Refine → Finding → Handoff**

The module helps learners understand why 3.1–3.7 are taught in their current order before they begin the detailed hunt lessons.

## Curriculum status

**Orientation module — no proficiency mapping.**

`3.0` is a navigation/introductory number. It does not create a new knowledge or task requirement in the proficiency matrix.

## Concepts introduced

- threat hunting as a bounded analytical process
- question and hypothesis
- internal evidence vs external/CTI leads
- iterative refinement
- scope and telemetry limits
- negative-result evidence boundaries
- detection gaps vs visibility gaps
- multi-owner hunt handoffs
- relationship among 3.1–3.7
- recurring A12 scenario as connective tissue
