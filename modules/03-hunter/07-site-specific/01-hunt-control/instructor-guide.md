**Estimated Time:** 60–75 minutes  
**Delivery Method:** Instructor-led with hands-on analysis

---

## Module Overview for Instructors

**Purpose of this module:**  
A new hunter must **obtain** how this site starts, controls, and parks hunt leads. This course **does not** publish that process. Fail invented queues.

**Key Teaching Points:**
- Keep it simple: these things **vary from site to site**.
- Hunter **B / C / C** · **3c / 4c / 4c**. SOC/CTI **A / A / B** · **1a / 1a / 2b**. Do not collapse.
- If *you* overlay a real site path, students may follow *that* text only.
- **2.6.3** is the hunt line. This hour is the site gate.

**Common Student Challenges:**
- Writing a tidy fake Jira / ServiceNow path so the exercise “has an answer.”
- Starting Night Owl because the pattern is good.
- Using another unit’s example as this section’s policy.

**Required Materials:**
- Student Guide
- Slide Deck
- Optional: *your* real site hunt-control slip (not in this repo)
- Answer key (this guide)

## Detailed Teaching Notes

**Talking Points:**
- “Follow” = obtain and use the path you were shown. It is not “compose a SOP.”
- If you *do* read a real path in class, that is item B. Still fail anyone who adds a second invented board.
- The Run-key hunt is the *work*, not the *process*.

**Question:**  
“What would you write on the orientation line if I have not shown you a path?”

## Knowledge Check – Answer Key

1. **Why no process here?**  
   **Answer:** Every site has its own. This course is not that site.  
   **Explanation:** Outline a–b.

2. **First task?**  
   **Answer:** Ask the lead and record whether you have the path.  
   **Explanation:** Orientation.

3. **Orientation line?**  
   **Answer:** Which path, who you asked, have / do not have, next step.  
   **Explanation:** Product.

4. **Open the hunt with no path?**  
   **Answer:** No.  
   **Explanation:** Example 1 / 3.

5. **Where hunts are written down?**  
   **Answer:** **2.7.2**.  
   **Explanation:** Fence.
