# Course Summary – Bringing the Defensive Workflow Together

**Path:** `modules/course-summary`

## Purpose

This is the final synthesis module for the complete training plan.

It reconnects:

**0.x Shared Foundations → 1.x SOC → 2.x CTI → 3.x Threat Hunting → 4.x Detection Engineering**

into the course-wide feedback loop:

**Observe → Understand → Search → Improve Coverage → Observe Again**

## Curriculum status

**Course synthesis — no proficiency mapping.**

This module is intentionally unnumbered so it does not create a new 5.x role track or a new proficiency requirement.

## Updated CTI model

The course summary reflects the reorganized 2.x sequence:

**Requirement → Collect → Evaluate → Enrich → Correlate → Assess → Produce → Disseminate**

It includes:

- RFI intake and requirement definition
- analytical tradecraft
- ATT&CK / Diamond / Kill Chain
- question-driven platform selection
- the two-pass platform model
- IOC/file/RDAP/DNS/infrastructure enrichment
- DTF's infrastructure-focused boundary
- correlation and link analysis
- candidate relationship vs campaign vs attribution
- applicability / visibility / relevance / impact
- STIX / finished intelligence
- RFI response, closure, and dissemination
- local CTI process

## Primary exercise

A12 is carried through the entire defensive loop:

1. SOC observes and investigates.
2. CTI answers the intelligence requirement.
3. Hunting searches for related internal activity.
4. Detection Engineering turns appropriate findings into maintained coverage.
5. Future coverage returns improved visibility to SOC.
