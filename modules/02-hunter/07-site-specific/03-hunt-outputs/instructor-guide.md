# Instructor Guide – Module 2.7.3 – Hunt Outputs and Hand-off

**Target Audience:** Threat Hunter (primary), SOC Analyst and CTI Analyst (secondary)  
**Proficiency Focus:**  
- Hunter: 2.7.3 B / C / C · 2.7.3.1 3c / 4c / 4c  
- SOC: 2.7.3 A / A / B · 2.7.3.1 1a / 1a / 2b  
- CTI: 2.7.3 A / A / B · 2.7.3.1 1a / 1a / 2b  
**Estimated Time:** 60–75 minutes  
**Delivery Method:** Instructor-led with hands-on analysis

---

## Module Overview for Instructors

**Purpose of this module:**  
A new hunter must **obtain** what this site expects as hunt output and **who** receives the hand-off. This course **does not** publish that chart. Fail invented recipients.

**Key Teaching Points:**
- Same simple point: these things **vary from site to site**.
- Hunter **B / C / C** · **3c / 4c / 4c**. SOC/CTI **A / A / B** · **1a / 1a / 2b**.
- Students may *know* hunts often go to SOC / IR / CTI. They may not name Harbor queues.
- **1.6** classroom notification matrix is **not** this hunt chart (item C fails).

**Common Student Challenges:**
- “Always page IR for Night Owl.”
- Using 1.6 as the hunt hand-off.
- DM a friend and call it handed off.

**Required Materials:**
- Student Guide
- Slide Deck
- Optional: *your* real site hand-off slip
- Answer key (this guide)

## Knowledge Check – Answer Key

1. **Why no chart here?**  
   **Answer:** Every site lists its own outputs and recipients.  
   **Explanation:** Outline a–b.

2. **Two local things?**  
   **Answer:** Required outputs, and who/how you hand off.  
   **Explanation:** Outline a–b.

3. **Orientation line?**  
   **Answer:** Outputs/hand-off, who you asked, have / do not have, next step.  
   **Explanation:** Product.

4. **Send with no chart?**  
   **Answer:** No.  
   **Explanation:** Example 1 / 3.

5. **SOC report types?**  
   **Answer:** **1.6**.  
   **Explanation:** Fence.
