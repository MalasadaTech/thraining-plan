# 2.0 – Cyber Threat Intelligence

**Path:** `modules/02-cti/00-intro`

## Purpose

This is the orientation module for the reorganized 2.x CTI block.

It introduces the sequence:

**Requirement → Collect → Evaluate → Enrich → Correlate → Assess → Produce → Disseminate**

The module helps learners understand why 2.1–2.8 are taught in their current order before detailed CTI instruction begins.

## Curriculum status

**Orientation module — no proficiency mapping.**

`2.0` is a navigation/introductory number. It does not create a new knowledge or task requirement in the proficiency matrix.

## Concepts introduced

- requirement-driven intelligence work
- collection vs analysis
- tradecraft before conclusions
- frameworks as organizing structures
- question-driven platform selection
- two-pass platform model
- enrichment and candidate pivots
- correlation and evidence-backed relationships
- applicability / visibility / relevance / impact
- production and RFI closure
- local CTI workflow
- recurring A12 requirement as connective tissue
