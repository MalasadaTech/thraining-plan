# Instructor Guide – Module 3.12.1 – Local Intelligence Requirements and Priorities

**Target Audience:** CTI Analyst (primary), Threat Hunter (secondary)  
**Proficiency Focus:**  
- SOC: 3.12.1 A / A / A · 3.12.1.1 1a / 1a / 1a  
- Hunter: 3.12.1 A / A / B · 3.12.1.1 1a / 1a / 2b  
- CTI: 3.12.1 B / C / C · 3.12.1.1 3c / 4c / 4c  
**Estimated Time:** 60–75 minutes  
**Delivery Method:** Instructor-led with hands-on analysis

---

## Module Overview for Instructors

**Purpose of this module:**  
A new analyst must **obtain** the section’s current PIRs / priorities and **align** work to them. This course **does not** publish those PIRs. Fail invented lists.

**Key Teaching Points:**
- SOC is **A / A / A** and **1a / 1a / 1a**. Hunter **A / A / B**. CTI **3c / 4c / 4c**. Do not collapse.
- If *you* overlay a real site list in class, students may align Night Owl to *that* text only. Do not ask them to write PIRs.
- 3.1.4 is how to *author* a requirement. One recap sentence, then orientation.
- Invented “Harbor PIR-1” is a fail even if it sounds plausible.

**Common Student Challenges:**
- Writing a tidy fake PIR list so the exercise “has an answer.”
- Treating Night Owl as automatically in focus.
- Using another unit’s example as this section’s policy.

**Required Materials:**
- Student Guide
- Slide Deck
- Optional: *your* real site PIR slip (not in this repo)
- Answer key (this guide)

## Detailed Teaching Notes

**Talking Points:**
- “Identify” = obtain and record the source. It is not “compose.”
- If you *do* read a real PIR in class, that is item B. Still fail anyone who adds a second invented PIR.
- Night Owl is the *work*, not the *requirement*.

**Question:**  
“What would you write on the orientation line if I have not shown you a list?”

## Hands-On Exercise – Instructor Guidance

**Align:**

| Item | Result |
|------|--------|
| A | **Still need the list** — cannot claim in focus |
| B | Align only if you overlaid a real PIR; else same as A |
| C | **Fail** — prior example is not this section’s list |

## Knowledge Check – Answer Key

1. **Why no list here?**  
   **Answer:** Every org/section has its own current PIRs. This course is not that section.  
   **Explanation:** Outline a.

2. **First task?**  
   **Answer:** Obtain the current local list (ask / go where the lead points). Do not invent it.  
   **Explanation:** Task 1.

3. **Orientation line?**  
   **Answer:** Who you asked, where they pointed, have/do not have the list, next step.  
   **Explanation:** Task 1.

4. **Night Owl in focus without a list?**  
   **Answer:** No.  
   **Explanation:** Task 2 / Example 3.

5. **Where do you write a PIR?**  
   **Answer:** **3.1.4** — and only if that is actually your job. Not this hour.  
   **Explanation:** Fence.
