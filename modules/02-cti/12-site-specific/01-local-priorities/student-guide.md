# Module 2.12.1 – Local Intelligence Requirements and Priorities

**Target Audience:** CTI Analyst (primary); Threat Hunter, SOC Analyst (secondary)  
**Proficiency Focus:**  
- CTI: 2.12.1 B / C / C ; 2.12.1.1 3c / 4c / 4c  
- Hunter: 2.12.1 A / A / B ; 2.12.1.1 1a / 1a / 2b  
- SOC: 2.12.1 A / A / A ; 2.12.1.1 1a / 1a / 1a  
**Estimated Time:** 20–25 minutes

---

## Learning Objectives

By the end of this module, you will be able to:

1. Say that **local PIRs / priorities** exist at the shop, and how you **obtain** them.
2. Align work to a stated local requirement — or record that you **do not have the list yet**.

**Mapped Proficiency Items:**
- K: 2.12.1 – Local intelligence requirements and priorities
- T: 2.12.1.1 – Identify current local priorities and align analytic work to them

---

## 1. Key Concepts

CTI analysts **obtain** the shop’s current priorities. They do **not** invent a DYA PIR list. PIR *concept* is **2.1.4**. Collection *planning* is **2.1.8**. This hour is **the local card**.

| You do | You do not |
|--------|------------|
| Ask where the current PIR / priority list lives | Invent PIR-01 for DYA |
| Align **A12** to a stated local item **if the card has one** | Pretend a list exists when it does not |
| Write **do not have the list yet** | Fill a classroom PIR as org policy |

**What good looks like:** “I obtain the current priority list from [role/place the instructor names, or my lead]. If the card lists ‘payload hosts on user VLANs,’ **A12** aligns. If there is no card: **I do not have the list yet.**”

---

## 2. Knowledge Check

1. You should invent a DYA PIR list so the exercise has numbers. True or false?
2. What do you do if the shop has not given you the list yet?
3. If a local card says “payload hosts on user workstations,” does **A12** align? Why?

---

## 3. Summary

Obtain the list. Align if it exists. Write “not yet” if it does not. Do not invent PIRs.
