## Module Overview for Instructors

**Purpose of this module:**  
Draft a finished A12 product and a cluster profile. Fail hash dumps and nation-state invention.

**Context (plain language):**

- What this hour is for: CTI analysts ship the judged answer.
- How it hooks to the hour before: 2.10.2 was machine-readable links.
- How it hooks to the hour after: 2.11.2 is who gets it and how.
- Why we are doing it this way: Short 0.x / 4.x voice. Outline a–c. No invented country.
- What we are *not* doing this hour: Local approval path. Channel list. STIX authoring. No lab.
- Extra step: none.

**Key Teaching Points:**
- Structure: question, know, judge, so-what, caveat.
- Profile = cluster, not country.

- Student Guide
- Slide Deck

## Knowledge Check – Answer Key

1. **TIP paste is finished. True or false?**  
   **Answer:** False.  
   **Explanation:** Outline c.

2. **Three elements?**  
   **Answer:** Any three: question, what you know, judgment, so-what, confidence/caveat.  
   **Explanation:** Outline b.

3. **Three-line A12 profile, no country?**  
   **Answer:** Cluster uses encoded PS + update domain + distinctive NS; victim WS-JLEE; vendor APT name is a label only.  
   **Explanation:** Task 2.
