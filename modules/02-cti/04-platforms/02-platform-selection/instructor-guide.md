# Instructor Guide – Module 2.4.2 – Selecting Platforms for CTI Work

**Estimated Time:** 10–15 minutes

## Purpose

1. Select a source for a defined CTI question and explain what the lookup can establish.
2. Capture an evidence record that preserves the object, source, time, result, and limitation.

## Teaching Sequence

1. Build on 0.7 rather than repeating vendor introductions. Give the class one question and ask what source could answer it.
2. Demonstrate retrieval and evidence capture with a supplied result. Record the source, object, time, finding, and limitation.
3. Use the two-pass delivery notes in 2.4.3–2.4.6: short orientation here, detailed method application in 2.5. Total lesson time is shared between passes.
4. Consult local access and handling rules before any live operation. Static results are sufficient for the classroom task.

## Knowledge Check – Answer Key

1. It starts with an intelligence question and selects a source expected to change the analysis. The result is recorded with its limitations.
2. Silent Push or an approved passive-DNS source; retain the returned observation window and source/report or query time.
3. Local handling rules and permissions govern external disclosure. Use an approved existing report or static classroom result when submission is not authorized.
