## Concepts taught

- purpose and core functions of the internal TIP
- repository ownership versus source provenance
- navigating and searching by the correct object type
- interpreting TIP hits and misses
- evaluating provenance, age, relationships, and sightings
- using TIP context for enrichment, analysis, and production
- recording relationships only when supported by evidence
