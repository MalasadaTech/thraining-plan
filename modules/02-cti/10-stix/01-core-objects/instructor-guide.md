## Module Overview for Instructors

**Purpose of this module:**  
Label syllabus STIX 2.1 objects in a classroom bundle. Do not invent types.

**Context (plain language):**

- What this hour is for: CTI analysts name the object they are sharing.
- How it hooks to the hour before: 2.9.4 closed platforms.
- How it hooks to the hour after: 2.10.2 is relationships / TAXII consume.
- Why we are doing it this way: Short 0.x / 4.x voice. Outline a–k. Spec is STIX 2.1 (not a hunt ID).
- What we are *not* doing this hour: Authoring a bundle. TAXII server. Actor profile. No lab.
- Extra step: none.

**Key Teaching Points:**
- Identity (victim) ≠ Threat Actor.
- Vendor name ≠ Threat Actor.

## Knowledge Check – Answer Key

1. **Invent a type if none fits. True or false?**  
   **Answer:** False.  
   **Explanation:** Stay-in.

2. **Four objects?**  
   **Answer:** Any four from the syllabus list.  
   **Explanation:** Outline a–k.

3. **Hash vs WS-JLEE?**  
   **Answer:** Indicator (or Observed Data) vs Identity.  
   **Explanation:** Task 1.
