## Module Overview for Instructors

**Purpose of this module:**  
Fill four vertices from A12. Name the weakest. Reject vendor-name Adversary.

**Context (plain language):**

- What this hour is for: CTI analysts see know / don’t-know on a product.
- How it hooks to the hour before: 2.7.1 was T-IDs.
- How it hooks to the hour after: 2.7.3 is ordered stages.

- What we are *not* doing this hour: ATT&CK IDs. Beacon POST (not main plot). No lab.
- Extra step: none.

**Key Teaching Points:**

- Label ≠ fill.
