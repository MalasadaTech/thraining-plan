# 1.0 – SOC Analyst Fundamentals

**Path:** `modules/01-soc/00-intro`

## Purpose

This is the orientation module for the 1.x SOC block.

It introduces the sequence:

**endpoint evidence → network evidence → detection logic → alert investigation → reporting/handoff**

The module helps learners understand why 1.1–1.5 are taught in that order before they begin detailed technical lessons.

## Curriculum status

**Orientation module — no proficiency mapping.**

`1.0` is a navigation/introductory number. It does not create a new knowledge or task requirement in the proficiency matrix.

## Concepts introduced

- evidence-to-handoff SOC workflow
- endpoint vs network evidence
- detection as a lead into investigation
- evidence boundaries
- relationship among 1.1–1.5
- recurring A12 scenario as connective tissue
- reporting/handoff as the end of the SOC workflow
