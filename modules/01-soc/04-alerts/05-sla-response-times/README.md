# SLA / Response Time Goals

**Path:** `modules/01-soc/04-alerts/05-sla-response-times`  
**Primary role:** SOC Analyst  
**Secondary:** Threat Hunter, CTI Analyst  
**Time:** about 20–25 minutes

## Purpose

Response-time goals help ensure an alert receives attention and reaches an appropriate next state. Keeping each goal’s start point and completion event explicit makes overdue work visible without encouraging premature closure.

## Concepts taught

- start clock (time to begin investigation)
- close/escalate clock (time to process)
- identifying which clock is at risk
- recording a close or escalate against the correct clock
