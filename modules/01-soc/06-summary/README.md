# 1.6 – SOC Analyst Section Summary

**Path:** `modules/01-soc/06-summary`

## Purpose

This is the closing synthesis module for the 1.x SOC block.

It revisits the workflow introduced in 1.0:

**endpoint evidence → network evidence → detection logic → alert investigation → reporting/handoff**

The summary uses the A12 scenario to reconnect 1.1–1.5 into one end-to-end SOC workflow rather than reteaching the individual lessons.

## Curriculum status

**Section summary — no proficiency mapping.**

`1.6` is a review/synthesis number. It does not create a new knowledge or task requirement in the proficiency matrix.

## Concepts reinforced

- evidence-to-handoff SOC workflow
- endpoint vs network visibility
- observation vs conclusion
- detection match vs maliciousness
- TP/FP/TN/FN vs activity category
- false-positive classification vs false-positive cause
- alert clocks vs reporting clocks
- incident report vs RFI
- recipient vs approved dissemination path
- evidence gaps and uncertainty
- SOC-to-CTI handoff

## Primary exercise

One integrated A12 evidence card is used to produce:

- host evidence
- network evidence
- detection explanation
- assessment
- remaining gap
- report/handoff
