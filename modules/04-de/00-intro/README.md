# 4.0 – Detection Engineering

**Path:** `modules/04-de/00-intro`

## Purpose

This is the orientation module for the 4.x Detection Engineering block.

It introduces the lifecycle:

**Need → Coverage Decision → Build/Change → Validate → Deploy → Monitor → Improve/Retire**

The module helps learners understand why 4.1–4.8 are taught in their current order before they begin the detailed Detection Engineering lessons.

## Curriculum status

**Orientation module — no proficiency mapping.**

`4.0` is a navigation/introductory number. It does not create a new knowledge or task requirement in the proficiency matrix.

## Concepts introduced

- maintained detection capability
- defensive need and nomination
- reuse existing coverage before adding new rules
- rule syntax vs production detection capability
- positive, benign-control, and data validation
- telemetry/data-path dependencies
- lifecycle monitoring and maintenance
- tune/change/replace/retire decisions
- detection vs enforcement/control ownership
- relationship among 4.1–4.8
- recurring A12 scenario as connective tissue
