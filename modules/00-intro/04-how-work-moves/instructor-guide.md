## Module Overview for Instructors

**Purpose of this module:**  
Walk one possible path of work after an alert, using the jobs named in 0.3.

**Context (plain language):**

- What this hour is for: Name the steps so later lessons sit on a shared path.
- How it hooks to the hour before: 0.3 named each job in one sentence. This hour is the path between those desks.
- How it hooks to the hour after: 0.5 is overlap — same evidence, different product, and one person may wear two hats.
- Why we are doing it this way: You wanted the course (and the later story) to follow this flow. Desks first, then the path.
- What we are *not* doing this hour: How to triage, write an RFI, hunt, or write a rule. No lab. No DYA tickets. Not the companion story.
- Extra step: none.

Say **RFI** (already glossed in 0.3): Request for Information.

**Key Teaching Points:**
- One possible path, not every shop.
- Extra infrastructure → block (firewall / IA). Hunt package → hunters and detection engineers.
- Two hats is 0.5, not this hour.

## Knowledge Check – Answer Key

1. **After triage, besides asking intel?**  
   **Answer:** Send it to incident response and notify leadership.  
   **Explanation:** Outline b.

2. **Extra infrastructure goes to the hunt team. True or false?**  
   **Answer:** False. Extra infrastructure can go to whoever blocks (firewall / IA). Hunters get a hunt package.  
   **Explanation:** Outline e vs f.

3. **Hunt package besides hunters?**  
   **Answer:** Detection engineers, to write or tune rules.  
   **Explanation:** Outline g.
